# Лабораторная работа 4 — анализ тональности отзывов

Проект посвящён классификации русскоязычных отзывов о фильмах по тональности. Выполнены очистка текста и лемматизация, построены TF–IDF-признаки и обучена модель логистической регрессии. Результат доступен через приложение Streamlit.

## Содержание работы

1. Загрузка и проверка набора `kp_valid.csv`.
2. Нормализация текста: нижний регистр, удаление лишних символов, токенизация, стоп-слова и лемматизация через `pymorphy3`.
3. Построение признаков `TfidfVectorizer` с униграммами и биграммами.
4. Обучение `LogisticRegression` с балансировкой классов.
5. Проверка по Accuracy, precision, recall, F1 и матрице ошибок.
6. Запуск интерактивного предсказания тональности в браузере.

## Установка

```bash
python -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
```

## Обучение и запуск

Сохранённые модели уже включены в репозиторий. При необходимости повторного обучения:

```bash
python train_model.py
```

Запуск интерфейса:

```bash
streamlit run sentiment_app.py
```

В разделе «Предсказание» вводится текст отзыва и отображается его класс. В разделе «Оценка модели» метрики вычисляются по `kp_valid.csv`: Accuracy, classification report и матрица ошибок. Значения формируются приложением при открытии страницы.
